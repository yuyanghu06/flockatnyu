# tools / contacts

Model-facing wording for contacts operations. Named tool files describe actions; workflow/navigation files guide agent choices; field/result files explain arguments and returned outcomes. JavaScript retains schemas and enforcement.

Single-person actions resolve the user's intended target before selecting an
exact read or write. Same-name ambiguity ends tool selection for that action
and leads to a focused question. The requested change survives clarification;
explicit selectors, multi-contact read-only comparisons and unrelated clear
actions remain available.
