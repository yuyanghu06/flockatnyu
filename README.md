# NYU club campus map

A planned interactive 3D map of NYU's Manhattan campus, connecting buildings to
club events, daily updates, and shared resources. Google Calendar, Discord,
Google Drive, and a conversational assistant are planned integrations.

The workspace currently contains reusable map assets and a managed development
workflow. Application implementation has not started.
