# Discord archive milestone

M16 adds a separate daily Discord REST archive worker and member-scoped search to the existing Hono website backend. Channels are selected through /admin.html; original JSONB messages retain metadata, reply IDs and source links. Existing text/date/author search and optional extracted-text embeddings passed local acceptance after 75 integrated tests, five Chrome checks, API/production builds and independent review. The next authorized design uses individual messages for seven days, weekly summaries for older current-month messages and monthly summaries for previous months, retaining originals. Each message/summary JSON record will map to a vector using deterministic serialization; summary generation and this new embedding input contract are not implemented. Hosted migrations, live bot access, production member permissions and Railway scheduling remain pending. The orchestrator owns shared milestone state and immutable pass records.
