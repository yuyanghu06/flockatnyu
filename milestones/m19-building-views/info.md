# Building views and screen-wide return

Save the user's screenshot-facing campus building views with requested camera-height
reductions and let outward scrolling anywhere return a focused building to the prior
overview. Scope covers map camera configuration and input, with geometry and backend
work preserved. Eight views are implemented; the last Stern-labeled image is treated
as Silver Center under a disclosed assumption. Stern uses a close rotunda anchor.

Status: complete after numerical, independent input, production Chrome desktop/portrait
and evaluator acceptance. Current evidence and limitations live in milestone.md and
../../evidence/m19-building-views/. Exact image reconstruction, the original Chrome tab
and physical touch/trackpad remain unverified. Root owns shared journal writes;
specialists own only their assigned implementation, tests and evidence.
