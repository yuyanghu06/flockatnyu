# Server source

`index.js` starts Hono; `config.js` reads server environment; `app.js` guards status/chat/admin/tool routes and normalizes streaming; `providers/` contains provider protocol adapters and bounded tool selection; `knowledge.js` owns scoped general persistence. `discord/` implements the separate Discord archive, and `worker.js` invokes its bounded one-shot job when configured. `retrieval-tools.js` validates model/client filters and applies a trusted principal. No credentials belong in source or browser imports.

See [Discord archive](../docs/discord-archive.md) and the current milestone for setup, permissions and verified local behavior. Dependencies and the lock are installed; production member authentication and live deployment remain unresolved. M17 hosted schema/catalog checks passed; runtime PostgREST is verified with the user-supplied key; live Discord still awaits bot credentials/channel scope. discord/cli.js supplies preflight, explicit full-history registration, bounded local backfill and a strict Railway entrypoint.
