# Tech@NYU Drive skill

`SKILL.md` contains the public program context, canonical user-supplied monodrive root and source interpretation/navigation rules. Chat and the autonomous planner load the same content through the server skill loader. Actual folder IDs and filenames are discovered with authorized live tools; the private research catalogue is not shipped. A local Codex installation can use the same skill independently of the application runtime.

Known source IDs are read directly. Explicit Calendar-copy instructions preserve title/date/year/skip rules through corrections, use dated names as all-day labels, skip blank rows and complete clear rows through the bounded batch tool without a renewed approval or broad Calendar scan. The structured driveContent body has separate first-sheet/truncation limits.
